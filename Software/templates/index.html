Instructions

Hi there! Welcome to the Plested Lab Automatic Bath Perfusion App. Please follow the instructions carefully before proceeding.

Extremely important!

  • Always hit EXIT before closing the app! (Otherwise restarting the app will not the possible as easy.)
  • Do not use the Live Preview longer than you need to (max. 30 s).

Structure of the App

  • Left: Preview - Tools to get a first view of your sample.
  • Middle: Perfusion Experiment - Plan and start your automatic perfusion experiment.
  • Right: Preliminary Analysis - First glimpse of analysis of your automatic perfusion experiment data.

Before starting your perfusion experiment...

  1. Empty the waste bottle.
  2. Fill your solutions into the five reservoirs (100 ml Schott Duran bottles). For that, have a look at the reservoir mount (on the left, blue) and its corresponding numbering in order to correctly assign your solution names to the reservoir numbers.
  3. In order to remove air bubbles from the perfusion system, place a beaker beneath the green PEEK tubes and test the flow from all the reservoirs. Make sure that it displays a flow-rate! (If not, let the administrator know and close the app!) For each solution, let the liquid flow until you see a constant droplet formation, without any air bubbles. If there is no flow at all, the air bubbles are too big and the big pump needs to be attached to one reservoir only at a time + Start Test Flow button pressed in order to restore flow.
  4. Put your multi-well plate into the stage mount.
  5. Turn off the room light and put the black hood on the perfusion arm.
  6. Go to Preview → Live + Auto Contrast and adjust the z-position using the ASI controller wheel in order to get your sample into focus. (This is crucial for the software autofocus in the experiment.)
  7. The exposure time for the images has to be set via Preview → Exposure time. The finally set parameters will be used during the experiment.
  8. Try out the software autofocus for your samples and/or play around with the parameters. The finally set parameters will be used during the experiment.
  9. In order to correctly design your perfusion experiment, please go through all the 6 steps in Perfusion Experiment starting at the top.
  10. By default, the center coordinates of a well are used as ROI for the time-lapse acquisition. In Additional tools you can find alternatives:
    • AutoFOV does automatic cell segmentation and uses a dynamic threshold to count fluorescent cells. It chooses a FOV featuring > 20 and < 80 fluorescent cells.
    • ManuFOV lets the user choose their own preferred FOV. After starting the experiment, the preview window displays the current FOV and the preferred xy-coordinates can be set using the ASI stage controller.
  11. Please always restart the app after before starting a new experiment!

After your perfusion experiment...

  • Wash out the reservoirs using 20 % Ethanol / 80 % DI water, fill them with at least 20 ml each and test the flow from all the reservoirs for 30-60 s each. Also, make sure to clean the syringes and attached tubes and fill with 20 % Ethanol / 80 % DI water.
  • Clean the syringe pumps using Perfusion Experiment → Clean Syringe Pumps.
  • Disconnect the blue fluidic adapters from the flow-rate sensor in order for it to dry.
  • You can let your dataset be analysed via Preliminary Analysis → Analyse Perfusion Experiment Data. You can also analyse another dataset when you enter the corresponding experiment name in Perfusion Experiment → 1. Location to Save Experiment Files.
  • Always hit EXIT before closing the app! (Otherwise restarting the app will not the possible as easy.)
